# Трекер фізичної активності

Android-застосунок для відстеження кроків, пройденої відстані та витрачених калорій. Написаний Java, працює з датчиком кроків або з акселерометром як резервним варіантом.

## Можливості

- Лічильник кроків у реальному часі через `Foreground Service`.
- Розрахунок дистанції та калорій на основі кількості кроків.
- Збереження лічильника між перезапусками застосунку.
- Кнопки старту, стопу та скидання.
- Перемикач мови Ukrainian / English без перезапуску.
- Сповіщення з поточними показниками під час активності.
- Логування через Timber: детальне в debug і лише важливе в release.

## Використані технології

- Java 17
- Android SDK 36, minSdk 24
- Gradle 8.14.3, Android Gradle Plugin 8.13.2
- AppCompat 1.8.0
- Timber 5.0.1
- JUnit 4.13.2

## Структура

- `app/src/main/java/com/fit/tracker/domain` — модель показників і розрахунки.
- `app/src/main/java/com/fit/tracker/sensor` — робота з датчиками та детектор кроків.
- `app/src/main/java/com/fit/tracker/data` — локальне збереження стану.
- `app/src/main/java/com/fit/tracker/service` — foreground service для відстеження.
- `app/src/main/java/com/fit/tracker/ui` — головний екран.
- `app/src/main/java/com/fit/tracker/util` — логування та локалізація.
- `app/src/main/res/values` — українські строки.
- `app/src/main/res/values-en` — англійські строки.

Розрахунки:

- дистанція = кроки × 0.75 метра;
- калорії = дистанція у кілометрах × 0.65 × 70 кг.

## Збірка

У корені проєкту:

```powershell
.\gradlew.bat test lintDebug assembleDebug --no-daemon
```

APK з'являться за шляхом `app\build\outputs\apk\debug\app-debug.apk`.

## Запуск

Запустіть проєкт в Android Studio на реальному пристрої або емуляторі. Мінімальна версія Android — 7.0 API 24.

Під час першого запуску застосунок запросить:

- `ACTIVITY_RECOGNITION` на Android 10 і новіших — для доступу до лічильника кроків;
- `POST_NOTIFICATIONS` на Android 13 і новіших — для сповіщення про активність.

Для емулятора потрібно окремо встановити Emulator та system image через Android Studio Device Manager. Давач `TYPE_STEP_COUNTER` може бути відсутній на емуляторі, тому для перевірки кроків бажано використовувати реальний телефон. Якщо апаратного лічильника немає, застосунок автоматично перемикається на акселерометр.

## Локалізація

Мову можна змінити кнопкою на головному екрані. Стан зберігається через `AppCompatDelegate.setApplicationLocales`. Початкова мова — українська.

## Логування

У debug-збірці логи пишуться повністю. У release-збірці `ReleaseTree` відкидає `VERBOSE` і `DEBUG`, а решту відправляє в Android Log. Перевіряти логи зручно через Logcat з тегом `FitTracker`.

## Тести

Юніт-тести покривають розрахунки показників і логіку детектора кроків на акселерометрі. Усі 8 тестів проходять і в debug, і в release конфігураціях.
